Мы группа Углицких Ильи и Шевченко Антона, отправляем идею и этапы нашего бота на согласование.

Проект: Telegram-бот-переводчик с голосовым интерфейсом

Фичи: Пользователь может отправить боту текст, который он переведёт на выбранный языкю
Бот распознаёт голосовое сообщение и переводит его на нужный язык
Бот возвращает и вернёт ответ не только текстом, но и голосом.
Помимо перевода, бот будет запоминать пользователей и их предпочтения, хранить историю переводов и показывать статистику использования.
